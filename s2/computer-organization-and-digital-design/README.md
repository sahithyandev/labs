# Computer Organization & Digital Design

Lab work for my Computer Organization & Digital Design module. Each `labN/` subdirectory is a Vivado project (Vivado 2018.2 WebPack), containing VHDL sources under `srcs/sources_1` and testbenches under `srcs/sim_1`.

## Structure

```
ip/
└── full_adder/       # Reusable full adder IP core (component.xml + src/sim)

lab1/                 # Intro Vivado project
lab2/                 # Combinational circuit + simulation
lab3/                 # Ripple-carry adders (4-bit, 8-bit)
lab4/                 # Decoders (2-to-4, 3-to-8) and 8-to-1 mux
lab5/                 # Binary multipliers (2-bit, 4-bit)
lab6/                 # Arithmetic unit, register, slow clock, decoder
lab7/                 # D flip-flop and counter
```
